# Forge Room Editor

## Keys

### Global

| Input       | Action             |
|-------------|--------------------|
| F1          | Polygon mode       |
| F2          | Vertex edit mode   |
| F3          | Face mode          |
| F4          | Transform mode     |
| f           | Mouse look         |
| w           | Move forward       |
| a           | Strafe left        |
| s           | Move backward      |
| d           | Strafe right       |
| Up          | Look up            |
| Down        | Look down          |
| Left        | Look left          |
| Right       | Look right         |
| +           | Increase grid size |
| -           | Decrease grid size |
| Shift + '+' | Move grid forward  |
| Shift + '-' | Move grid backward |

### Polygon Mode

| Input       | Action                    |
|-------------|---------------------------|
| Right click | Create brush from polygon |
| n           | New object at cursor      |

### Face Mode

| Input       | Action                                 |
|-------------|----------------------------------------|
| Right click | Context menu for current face          |
| r           | Align grid to current highlighted face |
| h           | Hide current face                      |
| Shift + h   | Hide all other faces for brush         |

## Brushes

Brushes are the primary building blocks of the world.
To create a brush, you need to enter polygon mode
