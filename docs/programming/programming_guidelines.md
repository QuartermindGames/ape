# Development Guidelines

If it wasn't obvious already, this engine isn't attempting to be advanced by any means. It's most certainly not aiming to compete with Unreal Engine 5, Unity, Godot or some other more advanced engine, as it's just not practical and this engine could better stand out with its own merits.

The guiding beacon for development: engines/games from the late 90s or early 00s. Basically anything before programmable shaders became more widely used in the industry. If you're considering a feature or change to the engine, it's worth considering if it's a feature that those earlier games included.

Below is a list of technology targets to perhaps keep in mind. Given my awful brain, these for me help focus me on a specific path going forward, rather than aimlessly flailing around as before.

- Unreal Engine 1 ➡ 2 (Unreal, Unreal II)
- id Tech 3 (Heavy Metal: F.A.K.K. 2, Return to Castle Wolfenstein)
- LithTech 1.0 ➡ 2.4 (Aliens Versus Predator 2, No One Lives Forever)
- Geo-Mod (Red Faction, Red Faction II)
- PreyTech (Prey 1997/1998)
