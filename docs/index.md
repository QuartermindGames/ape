# Getting Started

## Creating a new project

Projects can be found or added under the `release/projects/` directory.

This can be generated by Forge, Ape's editor, traditionally, however, if you prefer you can manually create a new folder under the above location and then create a `<project name>.prj.n` file.

The folder and mentioned file will both need to have the same name. I'd recommend using just an abreviation or simple name for simplicity.

An example of the contents required for the `.prj.n` file can be found below.

```
node.utf8
object project
{
    string name         "APE Base"
    string developer    "OldTimes Software"
    string website      "https://oldtimes-software.com"
    array int version   { 0 0 0 }

    bool visibleInEditor false

    array string mounts
    {
        "dev" "ship"
    }

    object cook
    {
        ; here is a list of properties for the cooking tool
        ; each of these arrays come in pairs - first is the source and then followed by destination

        array string worlds
        {
            ; explicit list of worlds, all dependencies will automatically be carried over
            "dev/worlds/example.wld.n"  "ship/worlds/example.wld.n"
        }

        array string materials
        {
            ; explicit list of materials
        }
    }
}
```

Again, the recommendation is to do this through Forge itself rather than manually.

# Launch Arguments

By default, the executable supports the following commands.

- **/cook** - automatically attempts to run the cook utility before launching the engine.
- **/project [projectName]** - mounts the given project.
- **+"[command]"** - allows you to pass a specific command to the engine on launch.
