# Developer Section

This area of the documentation is specifically focused on providing information and other details to those looking to contribute to the engine itself (which honestly is mostly going to be myself).

- [Coding Standards](dev_coding_standards.md)
  - Fairly self-explanatory, this provides some guidance on coding standards to follow. This isn't entirely strict as the style has evolved as work has continued, so generally the suggestion is to try and follow the style of the source file you're currently working in if you're not sure.
- [Guidelines](dev_guidelines.md)
  - Provides a rather basic guideline for the engine, when considering new features and so on.

If you have any questions or if anything is unclear, feel free to just get in touch.
