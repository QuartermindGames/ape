# Contributing

**I'm afraid I'm not willing to accept contributions at this time**, particularly because I've not yet decided on a formal licence yet.
Some earlier versions were made available under public-domain and LGPL, and these can be found on my blog [here](https://www.hogsy.me/ape.htm), but they're fairly useless.

----

The `master` branch is considered "stable", which at this early point in development doesn't really mean much. Active development is done under the `develop` branch, so that's where you should base your own changes upon.

Below are probably some of the most important documents to check out if you're looking to submit your own changes to the project.

- [General Guideline](docs/programming/programming_guidelines.md)
- [Coding Standards](docs/programming/programming_coding_standards.md)
- [Content Standards](docs/content_standards.md)

## AI Usage

**This project doesn't allow any AI generated code or art. Period.**

If you open a merge-request or issue, it's expected to be your words and your words alone. If you speak another language, you're allowed to use your native language and translate it with available tools (including those using AI) so long as the core of your own words are not lost.
